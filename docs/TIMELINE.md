# Urban Spoon — User Timeline Milestones

A simple timeline showing the journey of a user interacting with the platform.

```mermaid
timeline
    title Customer Journey Timeline
    Discovery : Visits Website
              : Views Homepage Hero
    Exploration : Checks "Our Menu"
                : Reads About Us
    Action : Clicks "Reserve a Table"
           : Fills out details
    Conversion : Submits Booking Form
               : Receives Confirmation Screen
    Fulfillment : Arrives at Restaurant
                : Enjoys Meal
```
